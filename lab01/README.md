# Лабораторна робота №1. Варіант 11: Мобільний тариф

## Опис проекту
Проект реалізує функціональний підхід до розрахунку місячної вартості мобільного тарифу.
Обчислювальне ядро не містить мутацій даних, глобального стану та I/O операцій.

## Структура
- `core.py`: Чисте функціональне ядро.
- `app.py`: Оболонка для виводу результатів (I/O).
- `tests/test_core.py`: Pytest-тести на детермінованість, відсутність мутацій та коректність політик.
