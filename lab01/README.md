# Лабораторна робота №1. Варіант 11: Мобільний тариф

## Опис проекту
Проект реалізує функціональний підхід для обчислення вартісних показників мобільного тарифу без мутацій вхідних даних та I/O операцій у розрахунковому ядрі.

## Запуск
1. Встановлення залежностей: `pip install -r requirements.txt`
2. Запуск програми: `python app.py`
3. Запуск тестів та перевірка типів: `pytest` та `mypy core.py`
